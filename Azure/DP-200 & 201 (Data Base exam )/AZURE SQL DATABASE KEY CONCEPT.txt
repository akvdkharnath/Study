Traditional Vs Modern Data ware house Architecture

Traditional Data ware house Architecture:
1. Geather data (logs,files,media,IOT,Saas,other cloud,data from apps)
2. Process the data (ETA)
3. Save data in Data ware house 
4. Analysis (OLT servers here storage and analatics are coupled togeather, if u use only storage still it will cost u for analatics (query))
5. Visulization of data 

Modern Data ware house Architecture:
1. Geather data (logs,files,media,IOT,Saas,other cloud,data from apps)(handels huge data types)
2. Data factory(Data lake to store the data, very less in cost)
   (Cost will be charges for only the resorce utilised)
3. From data lake it can be explored using data bases or data ware house  
3. From data lake it can clean or prepare or train and test data using ML tools and Data bricks
3. create and analysis data using BI tools and Data ware house
