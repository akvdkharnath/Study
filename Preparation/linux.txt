chmod:

Unix file permissions are divided into three categories:
1. User
2. Group
3. Others

Each category can have three types of permissions:
1. Read (r): User can read the file
2. Write (w): User can write to the file
3. Execute (x): User can execute the file


4 for Read

3: Write, Execute

1: Execute

777:
Owner: Read, Write, Execute
Group: Read, Write, Execute
Others: Read, Write, Execute

755: (Least Privilege)
Owner: Read, Write, Execute
Group: Read, Execute
Others: Read, Execute

644:
Owner: Read, Write
Group: Read
Others: Read
