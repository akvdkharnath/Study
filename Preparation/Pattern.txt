Software Architecture :
its a blueprint og building software 

1. Layered Pattern
2. Client-Server Pattern
3. Event-Driven Pattern
4. Microkernel Pattern
5. Microservices Pattern

Laye: red Pattern:
    1. each layer has task to do 
    2. each layer is independent
    3. one can modify with out effecting other 
    4.  a. Presentation layer (UI)
        b. Business layer (Backend)
        c. Application layer (communication between UI and Data)
        d. Data layer (DB)

    Ex: E-commerce web applications

Client-Server Pattern:
    1. it has server and multiple clinets 
    2. Server will have data (DB, files) Client will request and get response 
    Ex: Gmail, WWW, file sharing apps 

Event-Driven Pattern:
    1. its agile approach
    2. after task events will be triggered

    Ex: Notification system 

Microkernel Pattern:
    1. it has two blocks (core system and plug-in)
    2. core system: it handles main functions and operations of application 
    3. plug-in: softwares working on top of main application

Microservices Pattern: 
    1. small services all togeather makes an application 
    2. each service works independently
    3. modules are loosely coupled
