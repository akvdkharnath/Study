Docker: its solves problem of having same set of congigarations in all the env's using containers

Docker Benefits:
1. easy deployment
2. portability 
3. version control
4. Isolation

Docker Client: UI to intract eg: CMD, Terminal, powershell 

Docker File: its the guid or rule book to create docker image 

Docker Image: there are templates/blueprints used to create docker containers

Container: running instances of images 

Docker File -> Docker Image -> Container


Layers in Images:
1. Parent Image: includes the os layer & runtime layer
2. Source code layer
3. dependencies layer
4. CMD Layer


Dangling Images: there are the images assocated with a containers 

Docker Compose: its a tool to defin and run multiple-containers docker application
uses yaml files to config 

Docker Volumes: there are spaces allocated to containers to save data 
basically if no volume is specified containers will allocate space for data in side them so when ever we delete containers data will also be deleted 

Volumes Benefits:
1. decouple Container and Storage
2. Share same storage between different containers
3. deleting containers will not delete data in it 

-------------------------------- CMD -------------------------------

Basic:
service docker start 
service docker stop 
--help
docker system df --> space and stacks of docker  
docker system prune  --> will remove all unused images 

Images:
docker image ls  --> to get list of images in current folder
docker images    --> to get list of images in current folder
docker run <image name>     --> will run selected image
docker pull <image name>    --> will pull lates image
docker rmi <image id>       --> will delete image based on image id 
docker rmi -f <image id>    --> will delete image based on image id in force mode (even it is running)
docker build -t <image nme> .       --> to create a new image with selected name using docker file
docker build -t <image nme>:<tag> . --> to create a new image with selected name and tag using docker file
docker image prune          --> will remove unwanted images 

Containers:
docker ps                               --> list of containers
docker exec -it <container id> bash     --> login into containers
docker logs <container id> --follow     --> open logs of a container
docker kill $(docker ps -q)             --> kill all containers at a time 
docker container prune                  --> will remove unwanted container 
docker inspect <container id> -f "{{json .NetworkSettings.Networks}}"  --> to get assocated networks for container

Docker Compose:
docker-compose config  --> it will validate compose file 
docker-compose build   --> to buld the Container
docker-compose up      --> to start the Container
docker-compose down    --> to down the Container
docker-compose up --scale <service name>=<number of instances>  --> helps to scale perticular service scale up and down 
docker-compose logs --tail=200 -f <container name>        # ex: downstream
docker-compose up -d --force-recreate  <container name>    # ex: downstream
docker-compose pull <container name>
docker-compose down --remove-orphans 
docker-compose up --force-recreate

Volumes:
docker volume create <name>
docker volume inspect <name>   --> details for a specific volume 
docker volume prune            --> removes all unused volumes 
docker volume rm <name>
docker volume prune            --> will remove unwanted container

docker tag <python image>/<tag name> <repo name>/<image name>
