Deque: (https://youtu.be/34SNQHapJYE?si=uEFpus05jgv4bUBi)

helps to add and remove elements from both ends efficiently

from collections import deque
d = deque([1, 2, 3, 4, 5])

d.append(6) -> will add 6 to end
d.appendleft(0) -> will add 0 to start

d.pop() -> will remove and return the last item in this case 5
d.popleft() -> will remove and return the first item in this case 1

d.extend([7, 8, 9]) -> will add 7, 8, 9 to end
d.extendleft([-1, -2, -3]) -> will add -1, -2, -3 to start

d.rotate(-1) -> will rotate the deque by 1 position to clockwise
d.rotate(1) -> will rotate the deque by 1 position to anti-clockwise

How is it different from list:
Adding and removing from right/end   O(1) in list and O(1) in deque
Adding and removing from left/start  O(n) in list and O(1) in deque
Accessing elements by index          O(1) in list and O(n) in deque
Memory usage                         less in list and High in deque

c = Counter("hello world")

Memoization: 
1. allows you to optimize a Python function by caching its output based on the parameters you supply to it
2. It can be used to optimize the programs that use recursion
3. @memoize_factorial

memory = {}
def memoize_factorial(f):
     
    # This inner function has access to memory
    # and 'f'
    def inner(num):
        if num not in memory:
            memory[num] = f(num)
            print('result saved in memory')
        else:
            print('returning result from saved memory')
        return memory[num]
 
    return inner
     
@memoize_factorial
def facto(num):
    if num == 1:
        return 1
    else:
        return num * facto(num-1)
 
print(facto(5))
print(facto(5)) # directly coming from saved memory
