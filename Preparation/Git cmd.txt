# HEAD and HEAD~N info
Commits:  A -- B -- C -- D -- E (HEAD)
HEAD = E (latest commit)
HEAD~1 = D (one before latest)
HEAD~2 = C (two before latest)
HEAD~N = Nth commit before HEAD
Use HEAD/HEAD~N with many git commands (log, revert, reset, etc.)

revert (We use this to revert the changes made my a commit with out deleating there history)

Examples:
Commits:  A -- B -- C -- D -- E (HEAD)

git revert HEAD    
  Result:  A -- B -- C -- D -- E -- F (F undoes E, code = A,B,C,D)

git revert HEAD~1
  Result:  A -- B -- C -- D -- E -- F (F undoes D, code = A,B,C,E)

git reset --hard HEAD~1
  Result:  A -- B -- C -- D (HEAD)  (E removed, code = A,B,C,D)

git revert <commit-hash-of-C>
  Result:  A -- B -- C -- D -- E -- F (F undoes C, code = A,B,D,E)

git reset --hard <commit-hash-of-C>
  Result:  A -- B -- C (HEAD)  (D,E removed, code = A,B,C)

git revert HEAD~2..HEAD
  Result:  A -- B -- C -- D -- E -- F -- G -- H (F,G,H undo C,D,E)

git reset --hard HEAD~3
  Result:  A -- B (HEAD)  (C,D,E removed, code = A,B)

# file.txt         — Ignore this file in the root.
# *.ext            — Ignore all files with .ext extension anywhere.
# folder/          — Ignore this folder in the root.
# **/folder/       — Ignore any folder named 'folder' anywhere.
# prefix*          — Ignore all files starting with 'prefix' in the root.
# **/prefix*       — Ignore all files starting with 'prefix' anywhere.
# !file.txt        — Do NOT ignore this file (override previous rules).
# !folder/file.txt — Do NOT ignore this file inside folder/.
# **/file.txt      — Ignore any file named 'file.txt' anywhere.
# folder/*.ext     — Ignore all .ext files in folder/ (not subfolders).
# folder/**        — Ignore everything in folder/ and its subfolders.
# *.?ar            — Ignore files with any single character before 'ar' (e.g., .tar, .jar).
# /file.txt        — Ignore file.txt only in the root.
# **/name          — Ignore any file or folder named 'name' anywhere.
# !*.md            — Do NOT ignore any .md files.
