Centralized system: where all processing, data storage, and control are handled by a single central node (server or mainframe). 
All clients or users connect to this central point.

easy to manage, Single point of failure, 

Distributed System: system is a collection of independent computers (nodes) that work together as a single system. Data and processing are spread across multiple machines, often in different locations.

hard to manage, easy to scale up and down, Fault tolerance (if one failes other can take care)

------------------------------

Latency: Time take to for data to go  from one point to another point of system 
Low  Latency (need to be fast):  Eg: Online Gamming, Live Trading, Video conferance, Bidding application
High Latency (ok to be slow): Email, Reports tools (SAP, Tableau), Background processing tasks (Updates, batch processing)

Throughput: Amount of data can be processing in given time 

Low Throughput: Eg: Personal applications, HR applications in small scale, small inventory management

High Throughput: Eg: Payment gateways, Social system platforms, search engines,

Hashing: Process of comverting data to a fixed side of value (usually into int) out put is called hash value or hash code

Same input will have same hash value all ways 

small change in input will have a big differnce in hash value 

Why hashing 

Fast lookup (python dicts, java hash maps)
Secure (Encrypted data, Authentication)
Data Deduplication (Allows to skip deduplicate files )
Even distribution (Load Balancing (Consistent hashing))

Allocation: The procedure of providing memory to objects
1. Static Memory Allocation
2. Dynamic Memory Allocation

Static Memory Allocation:
1. memory allocation happens at the compile time (Ex: C, C++)
2. we cannot use the memory again in the further program
3. Stack data structure is used to store the static memory

Dynamic Memory Allocation:
1. memory allocation happens at the run time
2. can free update heap 
3. Heap data structure is used to store the dynamic memory

How to design a secure web API access:
1. Token based authentication
2. HMAC (Hash-based Message Authentication Code) authentication

Token based authentication Flow:
1. enter password 
2. if valid recive token 
3. send request using token 
4. if its a valid token recive response 

HMAC (Hash-based Message Authentication Code):
1. request API key 
2. receive API key 
3. Generate HMAC A key or signature at client side 
4. send request using generated signature
5. Generate HMAC B key or signature at Server side
6. compares HMAC A and HMAC B if valid send respons
