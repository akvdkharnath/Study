

Different types od DBMS languages:

Data definition language (DDL):
commands which are required to define the database.
E.g., CREATE, ALTER, DROP, TRUNCATE, RENAME, etc.

Data manipulation language (DML):
commands which are required to manipulate the data present in the database.
E.g., SELECT, UPDATE, INSERT, DELETE, etc.

Data Control Language (DCL):  
commands which are required to deal with the user permissions and controls of the database system.
E.g., GRANT and REVOKE.

Transaction Control Language (TCL):  
commands which are required to deal with the transaction of the database.
E.g., COMMIT, ROLLBACK, and SAVEPOINT.

a__  - starting with a and need to have atleast 3 char in word
