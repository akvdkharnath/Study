 What is the difference between a directive and a component in Vue?
Expected Answer: Candidates should clarify that directives are primarily used to directly manipulate the DOM, providing instructions to transform the DOM when the value of an expression changes (e.g., v-model, v-show). Components, however, are reusable and encapsulated Vue instances used to build the UI.

What are slots in Vue? Provide a use case.
Expected Answer: Slots are placeholders in a component that allow for content distribution. They let parent components fill in content in a designated place in the child component’s template. This is useful for creating component layouts that are reusable and adaptable to different content structures.
