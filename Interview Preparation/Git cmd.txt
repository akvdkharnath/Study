git init <folder path>   --> used to start a new repository
git clone <git url>      --> obtain a repository from an existing URL
git add <file name>      --> adds a file to the staging area
git add *                --> adds one or more to the staging area
git commit -m <message>  --> commit message
git diff <first_branch> <seconf_brnach> --> checks differences between the two branches
git reset <commit>       --> undoes all the commits after the specified commit and preserves the changes locally.
git reset –hard <commit> --> discards all history and goes back to the specified commit
git status               --> checks status 
git rm <file path>       --> removed the file and slach them 
git log                  --> get logs 
git show <commit>        --> shows changes for the specific commit 
git tag                  --> get list of tags 
git tag <tagname>        --> create new tags 
git checkout -b <branch name> --> creates a new local branch using thde current branch 
git stash                --> command temporarily stores all the modified tracked files
git stash save <message> --> command temporarily stores all the modified tracked files with the given comment 
git stash -u             --> stash only untracked files
git stash pop            --> apply recent stash to the current code and deleted the stash 
git stash apply          --> apply recent stash to the current code and keeps the stash 
git stash list           --> list all the stash things
git stash apply stash@{0} --> will apply provided stash
git stash show -p stash@{0}  --> this will show changes in the stach in terminal 
git stash drop           --> discards the most recently stashed changeset
git stash branch <branch_name> <stash_id>  --> Create a new branch to apply your stashed changes  and then delete that stash 
git push --set-upstream origin <branch name> --> creates a new origin branch from local branch
git reset --hard HEAD~1  --> if files are commited and not pushed use this cmd to revert the commit 
git reset --hard HEAD 
git checkout -b temp_branch stash@{0}  --> will convert a stash to a new branch
