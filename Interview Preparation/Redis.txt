Redis:
1. Stores everything in primary memory (in memory database)
2. R/W operations are extremely fast
3. Primary memory is in lesser in size and super costely
4. can also be used as primary DB like SQL

Normal Database:
1. Stores everything in secondary memory
2. R/W operations are slow
3. Secondary memory is in abundant in size 


DataTypes:
1. String
    Note − A string value can be at max 512 megabytes in length.

    SET name "tutorialspoint"    (will create varible name with tutorialspoint as value)
    GET name                     (will get value related to name varible)
    DEL name                     (will delete name varible)
    EXISTS name
    EXPIRE                       Sets the expiry of the key after the specified time in sec
    KEYS tutorial*               (will return all varible names starting with tutorial)
    STRLEN name                  len of varible
    TYPE name                    data type of value stored in varible 
2. Hashes
    A hash is a collection of key value pairs (dict)
    Note − Every hash can store up to 2^32 - 1 field-value pairs (more than 4 billion).
    
    HMSET user:1 username tutorialspoint password tutorialspoint points 200 
    HMSET myhash field1 "foo" field2 "bar"  (inserts multiple keys and values into system)
    HGET myhash field1                      (will get value related to field1 key in myhash varible)
    HKEYS myhash                            (List of keys in hash)
    HLEN myhash                             (Len of hash )
