Linux Directory Commands:
pwd        --> display the location of the current working directory
mkdir      --> create a new directory
rmdir      --> remove a directory
ls         --> list
cd <path>  --> change the current directory
cp <existing file name> <new file name>     --> copy a file or directory
mv <file name> <directory path>             --> move file 

Linux File commands:
touch <file name>               --> created empty file
touch <file1 name> <file1 name> --> created empty files 
cat <file name>                 --> view the file 
tac <file name>                 --> view the file reverse order 
more <file name>                --> view the very large file
rm <file name>                  --> delete the file 
head <file name>                --> view top 10 lines of file 
tail <file name>                --> view bottom 10 lines of file

Linux User Commands:
su <user name>       --> provides administrative access to another user
id                   --> display the user ID (UID) and group ID (GID)
useradd <username>   --> create new user 
passwd <username>    --> create user password
locate <file name>   --> search a file by file name
df                   --> display disk space 
du <file path>       --> display file space            
ip a                 --> get IP
ip addr              --> get IP


Vi Editor Commands:
vi <file name>   --> to open a file
i + Enter        --> insert mode 
:wq + Enter      --> save and quit 
:w + Enter       --> save
:q + Enter       --> quit
:q! + Enter      --> quit and discard changes 
:<start_line_number>,<end_line_number>d   --> will delete lines in the range 
:gg              --> cursor to first line
:G               --> cursor to last line
